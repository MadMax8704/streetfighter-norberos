# Street Fighter Norbertos

2D stick-figure brawler: punch, kick and combo through endless waves – boss every 5th wave.

## PWA

The game is installable as a Progressive Web App (works on desktop and mobile):

- `public/manifest.webmanifest` – app name, colors, icons (`standalone` display).
- `public/sw.js` – service worker: precaches the app shell so the game runs fully
  offline; navigation falls back to the cached shell when offline. The leaderboard
  endpoint (`/api/scores`) is always fetched from the network; when it is unreachable
  the game automatically falls back to its local `localStorage` board.
- Icons are generated by `scripts/make-icons.mjs` (no external dependencies):
  `node scripts/make-icons.mjs` rewrites `public/icon-*.png` and `public/apple-touch-icon.png`.
- `netlify.toml` sends `Cache-Control: no-cache` for `/sw.js` and the manifest so
  service-worker updates reach clients immediately through Netlify's CDN.

Install: the main menu has a **📲 INSTALL APP** button. In Chrome/Edge it opens
the native install dialog (`beforeinstallprompt`); where that is unavailable
(e.g. iPhone/Safari) it shows English, device-specific instructions instead
(iPhone: Safari → share button → "Add to Home Screen" → "Add").
If the app is already installed (standalone), the button hides itself.
