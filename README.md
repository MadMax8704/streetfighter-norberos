# Street Fighter Norbertos

2D stick-figure brawler: punch, kick and combo through endless waves – boss every 5th wave.

## Development

This game was developed entirely with a local model on an RTX 3090.
The work was done by an AI agent (DeepSeek Harness) running on a custom OS called
**NorbertOS**, powered by a tuned **Qwen3.8** model served via [unsloth](https://github.com/unslothai/unsloth).

Developer: **Norbertos**
